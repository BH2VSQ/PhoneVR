# PhoneVR 0.5.27 build fixes

This patch addresses the two compiler errors reported while building PhoneVR 0.5.26.

## SteamVR driver, MSVC C3668

`PhoneVRDaydreamController` derives from OpenVR's `ITrackedDeviceServerDriver`. The OpenVR interface does not provide a virtual destructor, so `~PhoneVRDaydreamController()` cannot be marked `override`. The destructor remains present and calls `Deactivate()`. The driver stores and deletes the objects as `PhoneVRDaydreamController*`, so concrete destructor dispatch is preserved.

## Android, Kotlin unresolved `LayoutParams`

`ScrollView` inherits from `FrameLayout` and uses `FrameLayout.LayoutParams` for its child. Replace the invalid `ScrollView.LayoutParams` reference with `FrameLayout.LayoutParams`. `MainActivity.kt` already imports `android.widget.FrameLayout`.

## Release script regression

The version bump helper previously required one exact suffix in the SteamVR driver startup log. The Daydream integration changed that log text, making the next version bump fail. The helper now updates the version number while preserving any `DisplayRedirect` suffix.

## Apply

This is an incremental patch from PhoneVR 0.5.26 to 0.5.27.

```powershell
git apply PhoneVR-0.5.27.patch
```
