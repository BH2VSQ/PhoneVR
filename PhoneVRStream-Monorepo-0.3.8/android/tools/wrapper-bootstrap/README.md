# PhoneVRStream Gradle bootstrap launcher

This small Java launcher uses the entry-point class name `org.gradle.wrapper.GradleWrapperMain` so the Android Studio Gradle integration and the supplied `gradlew` scripts can invoke it without a system-wide Gradle installation.

It intentionally supports only the features required by this repository:

1. Read `gradle/wrapper/gradle-wrapper.properties`.
2. Download the pinned Gradle distribution.
3. Verify `distributionSha256Sum` before extraction.
4. Extract the distribution under `GRADLE_USER_HOME/wrapper/dists/phonvrstream/`.
5. Forward all command-line arguments to the downloaded Gradle executable.

This is a repository-owned bootstrap implementation, not the upstream Gradle Wrapper JAR. The actual Gradle distribution is downloaded from the official Gradle distribution host. If this project later gains a normal Gradle installation in its development environment, the launcher can be replaced with the official wrapper generated by `gradle wrapper`.

Compile with a JDK:

```powershell
javac -source 8 -target 8 -encoding UTF-8 -d build tools/wrapper-bootstrap/src/org/gradle/wrapper/GradleWrapperMain.java
jar cfm gradle/wrapper/gradle-wrapper.jar manifest.txt -C build .
```
